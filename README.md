# Mobile Phone Data Analysis

An educational Python program that analyzes and visualizes a mobile phone dataset (2017–2025).

## Features

- Number of phones released per manufacturer
- Average phone price per manufacturer
- Most active manufacturer per year (2017–2025)
- Consistent units (grams, inches, mAh)
- Add, update the price of, or delete models, filtered by manufacturer
- Charts for the first three features

## Tech

Python 3, Regex, SQLite3, Matplotlib, NumPy, collections, DB Browser for SQLite, Jupyter Notebook

## Requirements

pip install matplotlib numpy

## Run

git clone https://github.com/borderlineping/MOBdata.git
cd MOBdata
python3 MOB.py

When it starts, the program shows charts of the starting data. After that, follow the on-screen prompts.
